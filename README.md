# Arcane Manager Stack (Local)

Docker Compose стек для развертывания локальной панели управления Arcane с подключением к Docker API.

## Архитектура и безопасность

* Панель использует подключение к `/var/run/docker.sock` с правами на запись (`rw`).
* Требуется симметричное монтирование директории с проектами Compose (пути на хосте и в контейнере должны совпадать) для корректной работы менеджера.
* Контейнер работает с ограничениями: `cap_drop: [ALL]`, `no-new-privileges: true` и жесткими лимитами CPU/RAM/PIDs.
* Для сбора системных метрик контейнеров используется режим `cgroup: host`.

## Требования

* Docker Engine >= 24.0
* Docker Compose >= 2.0

## Быстрый старт

### 1. Загрузка репозитория в директорию со стеками:
```bash
git clone <URL_репозитория> /opt/stacks/core-arcane-local
cd /opt/stacks/core-arcane-local
```

### 2. Подготовка файла окружения:

```bash
cp .env.example .env
chmod 600 .env
nano .env
```

**Важно перед запуском:**
1. Обязательно укажите внутренний IP-адрес интерфейса сервера в переменной `HOST_IP`.
2. Задайте корректный публичный адрес в переменной `APP_URL` (иначе сработает защита CSRF).
3. Сгенерируйте уникальный ключ шифрования командой `openssl rand -hex 32` и вставьте его в переменную `ENCRYPTION_KEY`.

### 3. Запуск стека:

```bash
docker compose up -d
```

Веб-интерфейс будет доступен по адресу `http://<HOST_IP>:<ARCANE_HTTP_PORT>`.

### 4. Инициализация:

Откройте веб-интерфейс по адресу, который вы указали в `APP_URL`.
При первом запуске система автоматически перенаправит вас на мастер первоначальной настройки, где потребуется создать первую учетную запись администратора и задать надежный пароль. 

## Права доступа

**Внимание:** Данная конфигурация использует прямое подключение к сокету Docker без промежуточной фильтрации. Панель обладает полными административными правами на создание, редактирование и удаление контейнеров, сетей и томов на этом сервере. Ограничьте сетевой доступ к порту панели и используйте надежные пароли.

## Обслуживание

Обновление версии образа:

1. Изменить тег `ARCANE_IMAGE` в файле `.env`.
2. Выполнить:

```bash
docker compose pull
docker compose up -d
```
